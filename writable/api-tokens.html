Create a token to connect an app, mobile client or automation to the DESTRA REST API. Tokens are shown once and stored only as a hash.

Quick start

Send the token as a bearer credential. Every request is scoped to the abilities you granted.

curl http://localhost:8080/api/v1/posts \
  -H "Authorization: Bearer dst_your_token_here" \
  -H "Accept: application/json"
Bearer auth Optional expiry Per-token abilities

Staying safe

  • Tokens are stored as one-way SHA-256 hashes.
  • Grant the smallest set of abilities that works.
  • Set an expiry for temporary integrations.
  • Revoke instantly — no password change required.
